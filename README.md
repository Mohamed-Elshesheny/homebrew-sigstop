# homebrew-sigstop

The Homebrew tap for [sigstop](https://github.com/Mohamed-Elshesheny/sigstop), a macOS menu bar break reminder for developers.

```sh
brew install --cask mohamed-elshesheny/sigstop/sigstop
```

The app is ad-hoc signed, not notarized, so macOS blocks it the first time. Clear the quarantine attribute once, or build it from source, which needs no clearing at all. Both are explained in the [install section](https://github.com/Mohamed-Elshesheny/sigstop#install) of the main repository.

Updates come through the app itself: Settings, About, Check for updates. This cask follows the GitHub releases.
